# Flutter Week 4 Lab: Gesture-Controlled Interface

# **Overview**

This applicatin was developed as a continuation of the Week 3 lab and expanded to include gesture-based interactions using GestureDetector widget.
Users can perform tap, long press, and swipe gestures on an interactive shape, with each gesture trigerring visual feedback and dynamic updates to the user interface.

# **Features**

- Tap gesture detection using GestureDetector and onTap()
- Long press gesture detection using GestureDetector and onLongPress()
- Swipe gesture detection using GestureDetector and onHorizontalDragEnd()
- Dynamic text updates using setState()
- Status messages that provide gesture feedback
- Dynamic color changes based on user interaction
- Shape transformation from square to circle using BoxDecoration
- Navigation between multiple screens using Navigator.push() and Navigator.pop()
- Homepage return functionality

# **Technologies Used**

- Flutter
- Dart
- Visual Studio Code
- Android Emulator

# **How to Run**

1. Open the project in Visual Studio Code.
2. Ensure Flutter is installed and configured correctly.
3. Open an Android emulator or connect a physical device.
4. Run the application
    flutter run
5. Navigate to the Gesture Demo screen.
6. Test the gestures:
    - Tap
    - Long Press
    - Swipe
